# Herramientas de apoyo

- `transcribir_clase.py`: crea una transcripción local en español con `faster-whisper`.
- `extraer_fotogramas.py`: extrae diapositivas puntuales de una grabación para verificar temario y criterios.
- `preparar_practica_eda.py`: genera y ejecuta la práctica de EDA a partir de la plantilla oficial.
- `preparar_archivo_videos.py`: al cerrar el curso, reúne cada MP4 con su VTT en un ZIP personal excluido de GitHub.

Estas herramientas son reproducibles, pero no forman parte de los archivos que se entregan al profesor.
