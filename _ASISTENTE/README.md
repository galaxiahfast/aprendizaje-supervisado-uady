# Material interno del asistente

Esta carpeta reúne archivos de respaldo y automatización. El estudiante no necesita recorrerla para
consultar clases ni preparar una entrega.

- `HERRAMIENTAS`: scripts de procesamiento y verificación.
- `PLANTILLAS_ORIGINALES`: copias sin resolver de materiales oficiales.
- `ARCHIVO_DE_VIDEOS.md`: procedimiento para generar el ZIP personal al terminar el curso.

Nada de esta carpeta debe enviarse al profesor salvo que una instrucción futura diga expresamente lo
contrario.
