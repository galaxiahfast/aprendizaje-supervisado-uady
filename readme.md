## Regla de nombres

Todos los archivos y carpetas usan minúsculas y palabras separadas con guiones. Las clases siguen
el formato `clase-01-aaaa-mm-dd-tema`. El prefijo `z-` identifica fuentes o material técnico que no
forma parte de una entrega.

Los videos permanecen únicamente en el equipo y están excluidos de GitHub. Las transcripciones
`.vtt` sí se conservan dentro de la carpeta de su clase.
