# Proyectos de Aprendizaje Supervisado

| Proyecto | Valor | Estado | Fecha límite |
| --- | ---: | --- | --- |
| Miniproyecto de regresión | 35 % | Aún sin instrucciones oficiales | No publicada |
| Miniproyecto de clasificación | 35 % | Aún sin instrucciones oficiales | No publicada |

El profesor comentó que el proyecto de regresión se anunciaría cerca del cierre de la segunda
semana y el de clasificación al final del curso. Son referencias de planeación, **no fechas de
entrega confirmadas**.

Cuando se publiquen, cada proyecto tendrá una carpeta propia con este formato:
`P01_REGRESION_TEMA` o `P02_CLASIFICACION_TEMA`. Dentro quedarán juntos las instrucciones, los
criterios de evaluación, el desarrollo y los archivos finales.
