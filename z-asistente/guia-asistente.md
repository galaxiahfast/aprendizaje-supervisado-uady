# Material interno del asistente

La letra `z` coloca esta carpeta al final. Aquí se guardan herramientas, plantillas originales y
archivos temporales. Este material no se entrega.

- `herramientas-asistente`: scripts de procesamiento.
- `plantillas-originales`: archivos oficiales sin resolver.
- `archivo-de-videos.md`: pasos para crear el ZIP personal del curso.
