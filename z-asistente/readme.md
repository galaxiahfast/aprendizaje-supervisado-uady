# Material interno del asistente

La letra `z` mantiene este material al final. Aquí se guardan automatizaciones y respaldos; no es
necesario abrir esta carpeta para estudiar ni debe copiarse a una entrega.

- `herramientas`: scripts de procesamiento y verificación.
- `plantillas-originales`: materiales oficiales sin resolver.
- `archivo-de-videos.md`: procedimiento para preparar el ZIP personal al terminar el curso.
