# Herramientas de apoyo

- `transcribir-clase.py`: crea una transcripción local en español.
- `extraer-fotogramas.py`: extrae diapositivas puntuales de una grabación.
- `preparar-practica-eda.py`: genera y ejecuta la práctica de EDA desde la plantilla original.
- `preparar-archivo-videos.py`: reúne al final del curso cada MP4 con su VTT.

Son herramientas internas y no forman parte de una entrega académica.
