# Material personal de la clase 1

La grabación local se guarda aquí como `clase-01-2026-10-19.mp4` y está excluida de GitHub mediante
`.gitignore`. La transcripción `.vtt` sí está en [`../fuentes/`](../fuentes/), porque sirve para
buscar temas y construir la ruta rápida.

Este directorio no debe copiarse a ninguna entrega académica.

Al terminar el curso, las grabaciones se reunirán en un ZIP para subirlo manualmente a Drive. Cada
video deberá ir acompañado por su `.vtt` y conservar el mismo nombre base.
